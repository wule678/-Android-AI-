## 一、准备工作（第一次做，之后不用重复）

### 第 1 步：打开 PowerShell

1. 按键盘左下角的 **Win 键**（Windows 图标）
2. 键盘输入 `powershell`
3. 点出现的 **Windows PowerShell**

> 打开后是一个蓝底白字的窗口，光标前面是 `PS C:\Users\29923>`

### 第 2 步：确认手机连上了电脑

1. 用 USB 线把手机连到电脑
2. 手机可能会弹"是否允许 USB 调试"，点**允许**
3. 在 PowerShell 里**复制粘贴**下面这行，回车：

```powershell
C:\Users\29923\AppData\Local\Android\Sdk\platform-tools\adb.exe devices
```

4. 看到类似下面这样，就说明连上了（有一串字符 + `device`）：

```
List of devices attached
10AD4U0Z8T003SR    device
```

> 如果显示 `unauthorized`（未授权），去手机上点"允许 USB 调试"。
> 如果下面空空的没设备，检查 USB 线、重新插一下。

### 第 3 步：启动 App

在 PowerShell 里粘贴这行，回车：

```powershell
C:\Users\29923\AppData\Local\Android\Sdk\platform-tools\adb.exe shell am start -n com.tencent.scrfdncnn/.MainActivity
```

手机屏幕上会打开 App（名字叫 scrfdncnn），出现摄像头画面。

> 第一次打开会弹"是否允许相机权限"，点**允许**。

## 二、怎么看画面上的数据（很重要！）

把脸对准手机**前置摄像头**，屏幕上会显示好几行字（白色底、黑色字），从上往下是：

| 画面上的字 | 含义 |
|---|---|
| `recog: known/unknown` | 识别结果（认出来/没认出来） |
| `liveness: real/spoof` | 活体结果（真人/攻击） |
| `queue: X/3 dropped: Y done: Z` | 队列状态、丢帧数、已处理帧数 |
| `det: Xms wait: Xms prep: Xms` | 各阶段耗时（检测/队列等待/预处理对齐+裁剪） |
| `FPS=xx.xx`（右上角） | 每秒帧数 |

**这些数字就是你要记录的数据**，对照《实验数据记录.md》的表格填进去就行。

## 实验一：测基线（不用改代码，先做这个）

**目的**：得到一组"正常情况"的性能数据，作为后面所有对比的参照。

**步骤**：

1. 启动 App，脸对准摄像头，**等 10 秒**让数字稳定
2. 打开手机自带的**秒表**（或者用手机计时）
3. 每隔 **5 秒**，低头看一眼画面，把这几个数抄到表里：
   - `FPS`
   - `det`、`wait`、`prep` 这三个耗时（prep = 预处理：对齐+裁剪）
   - `dropped`、`done`
4. 连续记 30 秒（也就是记 6 次：第 5、10、15、20、25、30 秒）
5. 重复做 **3 遍**（中间可以休息几秒）

> 记录表格：`实验数据记录.md` 里的「实验一」表格。

## 实验四：测精度（不用改代码）

### 4.1 活体检测

**准备**：一张**打印出来的照片**（你的脸）、另一部手机**显示你的照片**（屏幕翻拍）。

**步骤**：

1. 脸对准摄像头，看 `liveness` 是不是 `real` —— 记下来（应该判"真人"）
2. 把**打印照片**对准摄像头，看 `liveness` 是 `real` 还是 `spoof` —— 记下来（应该判"攻击"）
3. 把**另一部手机显示你的照片**对准摄像头，看 `liveness` —— 记下来（应该判"攻击"）
4. 每种测 **20 次**（真人 20 次、照片 20 次、翻拍 20 次），每次记"判对了还是判错了"

> 判错的（比如真脸被判成 spoof、照片被判成 real）要**截图保存**，作业要求"展示误判样例"。

### 4.2 人脸识别

1. 点「注册人脸」→ 输入名字（比如 `张三`）→ 确定
2. 再注册 2~4 个人（李四、王五……）
3. 脸对准摄像头，看界面上有没有显示「识别: 张三」等名字
4. 每个人测 **10 次**，记"正确认出几次"
5. 再测一个**没注册过的人**，看是不是显示「识别: 未知」—— 这就是"拒识"

> 记录表格：`实验数据记录.md` 里的「实验四」表格。

## 实验二：线程数对比（改一个文件：inferencenative.cpp）

> ⚠️ 注意：识别/活体现在跑在 `:inference` 进程，所以线程数要改 **inferencenative.cpp**（不是主进程的 edgeface/minifasnet/scrfd.cpp 了）。

**目的**：看"识别/活体推理线程数 1/2/4"对速度的影响。

**第 1 步：用记事本打开要改的文件**

按 Win 键 → 输入 `notepad` → 打开**记事本** → 菜单"文件 → 打开"，打开这个文件：

```
D:\Class\system\report\final\ncnn-android-scrfd-20261020.ba33907\ncnn-android-scrfd-20261020.ba33907\app\src\main\jni\inferencenative.cpp
```

**第 2 步：找到那一行并修改**

记事本里按 `Ctrl + F`（查找），输入：

```
num_threads
```

这个文件里有**两处** `num_threads`（一处加载识别模型、一处加载活体模型），**两处都要改**。

会找到类似这样的一行（共两处）：

```cpp
net.opt.num_threads = ncnn::get_big_cpu_count();
```

把**两处**都改成：

```cpp
net.opt.num_threads = 1;
```

然后**保存**（Ctrl + S），关掉记事本。

**第 3 步：重新构建 + 重新安装 + 测数据**

看下面「七、改代码后怎么重新构建和安装」。

测完"线程数 = 1"的数据后，把两处 `= 1;` 改成 `= 2;`，重复一遍；再改成 `= 4;`，再重复一遍。

> 记录表格：`实验数据记录.md` 里的「实验二」表格。
> 说明：现在识别/活体在独立进程，画面耗时显示没有 recog/live 了，线程数对比主要看 **FPS** 和整体流畅度。

## 七、改代码后，怎么重新构建和安装（每次都一样）

改完代码、保存后，在 PowerShell 里**依次**粘贴下面 3 段（一段一段来，等每段跑完再贴下一段）：

### ① 重新构建（约 30~60 秒，耐心等）

```powershell
cd D:\Class\system\report\final\ncnn-android-scrfd-20261020.ba33907\ncnn-android-scrfd-20261020.ba33907
$env:JAVA_HOME='C:/Users/29923/.jdks/jdk-17.0.21+9'
.\gradlew.bat :app:assembleDebug --console=plain
```

看到 `BUILD SUCCESSFUL` 就说明构建成功了。

### ② 重新安装到手机

```powershell
C:\Users\29923\AppData\Local\Android\Sdk\platform-tools\adb.exe install -r "D:\Class\system\report\final\ncnn-android-scrfd-20261020.ba33907\ncnn-android-scrfd-20261020.ba33907\app\build\outputs\apk\debug\com.tencent.scrfdncnn-debug.apk"
```

看到 `Success` 就装好了。

### ③ 重新启动 App

```powershell
C:\Users\29923\AppData\Local\Android\Sdk\platform-tools\adb.exe shell am force-stop com.tencent.scrfdncnn
C:\Users\29923\AppData\Local\Android\Sdk\platform-tools\adb.exe shell am start -n com.tencent.scrfdncnn/.MainActivity
```

然后回到实验步骤继续测。
