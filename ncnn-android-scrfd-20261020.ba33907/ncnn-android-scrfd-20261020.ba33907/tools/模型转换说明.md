# 模型转换说明（PyTorch .pt → ncnn，用 pnnx）

> ⚠️ 2026 新版 ncnn 已移除 `onnx2ncnn`，改用 **pnnx** 直接把 PyTorch 模型转成 ncnn，跳过 ONNX。步骤更少、精度更好。

## 0. 现状

- 模型已下载：`tools/models/edgeface_xxs.pt`（5.0 MB）、`tools/models/2.7_80x80_MiniFASNetV2.pth`（1.8 MB）
- ncnn 工具已解压：`tools/ncnn-20261020-windows-vs2019/`（`x64\bin\ncnnoptimize.exe` 等）
- 目标：生成 `edgeface_xxs.param/.bin`、`minifasnetv2.param/.bin` 放进 `app/src/main/assets/`

## 1. 环境准备（一个命令）

```bash
pip install torch pnnx
```

> 注意：`pnnx` 是命令行工具，`pip install pnnx` 装完后，`pnnx` 命令会自动进 PATH。

## 2. EdgeFace-XXS：导出 TorchScript → pnnx 转 ncnn

```bash
git clone https://github.com/otroshi/edgeface.git
cd edgeface
```

在 `edgeface/` 目录下新建 `export_xxs.py`：

```python
import torch
from backbones import get_model

model = get_model('edgeface_xxs')
ckpt = torch.load('../tools/models/edgeface_xxs.pt', map_location='cpu')
if isinstance(ckpt, dict) and 'state_dict' in ckpt:
    ckpt = ckpt['state_dict']
model.load_state_dict(ckpt)
model.eval()

x = torch.rand(1, 3, 112, 112)                    # 输入 112x112 RGB
mod = torch.jit.trace(model, x, check_trace=False)
mod.save('edgeface_xxs_script.pt')                # 导出 TorchScript
print('saved edgeface_xxs_script.pt')
```

运行：

```bash
python export_xxs.py
pnnx edgeface_xxs_script.pt inputshape=[1,3,112,112]
```

生成 `edgeface_xxs_script.ncnn.param` / `edgeface_xxs_script.ncnn.bin`。

## 3. MiniFASNetV2：导出 TorchScript → pnnx 转 ncnn

```bash
cd ..
git clone https://github.com/minivision-ai/Silent-Face-Anti-Spoofing.git
cd Silent-Face-Anti-Spoofing
```

在仓库根目录新建 `export_v2.py`：

```python
import torch, sys
sys.path.insert(0, '.')
from src.model_lib.MiniFASNet import MiniFASNetV2

model = MiniFASNetV2(embedding_size=128, conv6_kernel=(7, 7),
                     drop_p=0.2, num_classes=3, img_channel=3)
ckpt = torch.load('../tools/models/2.7_80x80_MiniFASNetV2.pth', map_location='cpu')
if isinstance(ckpt, dict) and 'state_dict' in ckpt:
    ckpt = ckpt['state_dict']
model.load_state_dict(ckpt)
model.eval()

x = torch.rand(1, 3, 80, 80)                      # 输入 80x80 RGB
mod = torch.jit.trace(model, x, check_trace=False)
mod.save('minifasnetv2_script.pt')
print('saved minifasnetv2_script.pt')
```

运行：

```bash
python export_v2.py
pnnx minifasnetv2_script.pt inputshape=[1,3,80,80]
```

## 4. 复制到 assets（改名为骨架期望的文件名）

把 pnnx 生成的 `.ncnn.param/.bin` 复制到 `app/src/main/assets/`，并重命名：

```
edgeface_xxs_script.ncnn.param  ->  edgeface_xxs.param
edgeface_xxs_script.ncnn.bin    ->  edgeface_xxs.bin
minifasnetv2_script.ncnn.param  ->  minifasnetv2.param
minifasnetv2_script.ncnn.bin    ->  minifasnetv2.bin
```

（可选）再用 ncnnoptimize 优化一遍（工具在 `tools/ncnn-20261020-windows-vs2019/x64/bin/`）：

```bash
ncnnoptimize edgeface_xxs.param edgeface_xxs.bin edgeface_xxs.param edgeface_xxs.bin 0
ncnnoptimize minifasnetv2.param minifasnetv2.bin minifasnetv2.param minifasnetv2.bin 0
```

## 5. 核对张量名（重要 ⚠️）

打开 `.param` 文件（文本），找输入/输出 blob 名，对照改 C++ 常量：

- `app/src/main/jni/edgeface.cpp`：`EDGEFACE_INPUT_NAME` / `EDGEFACE_OUTPUT_NAME`
- `app/src/main/jni/minifasnet.cpp`：`MINIFASNET_INPUT_NAME` / `MINIFASNET_OUTPUT_NAME`

> pnnx 默认输入名常是 `in0`、输出名常是 `out0`（以实际 `.param` 为准），
> 所以骨架里原来写的 `input.1` / `683` / `input` / `output` 很可能要改。

## 6. 预处理对照（已确认 ✅）

- EdgeFace-XXS：`mean=0.5, std=0.5`（等价 `(x-127.5)/127.5`）→ 骨架 `edgeface.cpp` 已用 `127.5/127.5`，无需改。
- MiniFASNetV2：输入 80×80，输出 **3 类 logits**（`index 1 = 真人`）→ 骨架 `minifasnet.cpp` 已按 3 类 softmax，无需改。
